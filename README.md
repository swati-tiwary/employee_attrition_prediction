# Employee Attrition Prediction

## Overview

This project uses Machine Learning to predict employee attrition — whether an employee is likely to leave an organization.

The model analyzes employee-related features and identifies patterns associated with attrition, helping organizations understand factors that may contribute to employee turnover.

## Objectives

- Predict employee attrition using machine learning
- Analyze employee data to identify attrition-related patterns
- Apply data preprocessing and feature analysis
- Train and evaluate a classification model
- Understand how machine learning can support HR decision-making

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning Model

**Random Forest Classifier**

Random Forest is used to predict employee attrition by combining multiple decision trees to improve prediction performance and reduce overfitting.

## Project Workflow

1. Data loading and exploration
2. Data preprocessing

4. Feature selection and preparation
5. Model training
6. Prediction
7. Model evaluation
